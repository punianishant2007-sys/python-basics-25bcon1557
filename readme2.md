# 🔢 Number Checkers in Python

This repository contains three simple Python programs to check different types of numbers:

1. **Prime Number Checker**
2. **Armstrong Number Checker**
3. **Pronic Number Checker**

These programs are created for practicing **Python fundamentals and problem-solving**.

---

## 📚 Programs Included

### 1. 🔵 Prime Number Checker

A **Prime Number** is a number greater than 1 that has only two factors: **1 and itself**.

**Examples:**

```text
2, 3, 5, 7, 11, 13, 17...
```

**File:**

```text
prime.py
```

---

### 2. 🟢 Armstrong Number Checker

An **Armstrong Number** is a number whose sum of its digits raised to the power of the number of digits is equal to the original number.

**Example:**

```text
153 = 1³ + 5³ + 3³
153 = 1 + 125 + 27
153 = 153
```

Therefore, **153 is an Armstrong Number**.

**File:**

```text
armstrong.py
```

---

### 3. 🟠 Pronic Number Checker

A **Pronic Number** is a number that can be expressed as the product of two consecutive integers.

**Example:**

```text
6 = 2 × 3
12 = 3 × 4
20 = 4 × 5
```

Therefore, **6, 12, and 20 are Pronic Numbers**.

**File:**

```text
pronic.py
```
