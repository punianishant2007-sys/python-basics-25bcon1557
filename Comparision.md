# 🔢 Number Checkers in Python

This repository contains three Python programs for checking different types of numbers.

## 📋 Program Comparison

| No. | Program                     | File Name      | What It Checks                | Example           |
| --: | --------------------------- | -------------- | ----------------------------- | ----------------- |
|   1 | 🔵 Prime Number Checker     | `prime.py`     | Whether a number is Prime     | `7 → Prime`       |
|   2 | 🟢 Armstrong Number Checker | `armstrong.py` | Whether a number is Armstrong | `153 → Armstrong` |
|   3 | 🟠 Pronic Number Checker    | `pronic.py`    | Whether a number is Pronic    | `6 → Pronic`      |

---

## 📊 Detailed Comparison

| Feature           | 🔵 Prime                        | 🟢 Armstrong                               | 🟠 Pronic                          |
| ----------------- | ------------------------------- | ------------------------------------------ | ---------------------------------- |
| **Definition**    | Number having exactly 2 factors | Sum of digit powers equals original number | Product of two consecutive numbers |
| **Example**       | `7`                             | `153`                                      | `6`                                |
| **Calculation**   | `7 → 1, 7`                      | `1³ + 5³ + 3³ = 153`                       | `2 × 3 = 6`                        |
| **Loop**          | `for`                           | `while`                                    | `for`                              |
| **Main Operator** | `%`                             | `%`, `//`, `**`                            | `*`                                |
| **Main Logic**    | Check divisibility              | Calculate digit power sum                  | Check consecutive product          |
| **Input**         | Integer                         | Integer                                    | Integer                            |
| **Output**        | Prime / Not Prime               | Armstrong / Not Armstrong                  | Pronic / Not Pronic                |
